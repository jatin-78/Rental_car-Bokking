# Car Rental Booking Backend

A backend API for a Car Rental Booking System built with Node.js, Express.js, TypeScript, and MongoDB.

## Tech Stack

- Node.js
- Express.js
- TypeScript
- MongoDB
- Mongoose
- JWT Authentication

## Features

- User registration
- User login
- Get user profile
- Update user profile
- Add cars
- Get all cars
- Get single car
- Create guest booking
- Create user booking
- Get all bookings
- Get my bookings
- Accept booking
- Decline booking
- Admin dashboard
- Get all users (admin)
- Get all bookings (admin)
